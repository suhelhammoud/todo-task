# TODO Task App (Express + Drizzle + Better Auth + SQLite + Bootstrap)

## Stack
- **Express.js** web server
- **Drizzle ORM** for database access
- **Better Auth** for authentication
- **SQLite** database
- **Bootstrap 5** for styling

## Setup
```bash
npm install
cp .env.example .env
npm run db:generate
npm run db:migrate
npm run dev
```

Open `http://localhost:3000`.
